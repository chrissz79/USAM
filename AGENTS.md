# USAM

Universal Sound Asset Manager

## Mission

USAM is a modular platform for:

- VST Plugin Management
- Sample Management
- Preset Management
- Kontakt Library Management
- Falcon Library Management
- HALion Library Management
- AI-assisted Search
- Hardware Integration

## Architecture Goals

- Modular
- Cross-platform
- Scalable
- Database-driven
- Plugin-based

## Current Target

Version 0.1

Features:

- VST Scanner
- Sample Browser
- Preset Browser
- SQLite Database
- Search Engine

## Tech Stack

Frontend:
- Electron
- React
- TypeScript

Backend:
- Node.js

Database:
- SQLite

## Coding Rules

- TypeScript preferred
- Clear comments
- Modular architecture
- Unit tests required
- No hardcoded paths
